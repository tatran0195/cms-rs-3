# cms-i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the `crates/cms-i18n` workspace crate to unify language resolution and catalog translation across transactional emails (`cms-mailer`) and localized API error responses (`cms-error` / `cms-middleware`) for UI rendering.

**Architecture:** Extract generic BCP-47 tag parsing, message interpolation, catalog fallbacks, and compile-time embedding from `cms-mailer/src/i18n` into a standalone leaf crate `crates/cms-i18n`. Wire Tokio task-local request scoping into `cms-middleware` so Axum handlers emit localized `error.message` strings directly in `AppError::into_response`, while refactoring `cms-mailer` to reuse `cms-i18n` without code duplication.

**Tech Stack:** Rust (Axum, Tokio task-local, Serde, Thiserror, Tracing), TypeScript (`@cms/sdk`, Paraglide messages JSON).

## Global Constraints

- Platform Scope: Internal company platform — no billing, plans, Stripe, or subscription features (per AGENTS.md / GEMINI.md).
- Single source of truth: translation messages live in `packages/i18n/messages/{locale}.json`.
- Zero runtime disk I/O dependency: compiled server slices are embedded via `build.rs` with boot-time audit.
- Server error security: 500 status codes never leak internal SQL or raw stack traces; they emit safe localized strings with correlation `errorId`.
- No handler signature changes: Axum handlers continue to return `Result<T, AppError>`.

- [ ] **Step 1: Write `crates/cms-i18n/build.rs`**

```rust
use std::{
    collections::BTreeMap,
    env, fs,
    path::{Path, PathBuf},
};

const BASE_LOCALE: &str = "en";
const DEFAULT_RELATIVE_DIR: &str = "../../packages/i18n/messages";

fn main() {
    println!("cargo:rerun-if-env-changed=CMS_I18N_MESSAGES_DIR");
    println!("cargo:rerun-if-changed=build.rs");

    let manifest = PathBuf::from(env::var("CARGO_MANIFEST_DIR").expect("CARGO_MANIFEST_DIR"));
    let dir = env::var_os("CMS_I18N_MESSAGES_DIR")
        .map(PathBuf::from)
        .unwrap_or_else(|| manifest.join(DEFAULT_RELATIVE_DIR));
    println!("cargo:rerun-if-changed={}", dir.display());

    let mut files: Vec<PathBuf> = fs::read_dir(&dir)
        .unwrap_or_else(|e| panic!("cannot read `{}`: {e}", dir.display()))
        .filter_map(Result::ok)
        .map(|e| e.path())
        .filter(|p| p.extension().is_some_and(|x| x == "json"))
        .collect();
    files.sort();

    let out_dir = PathBuf::from(env::var("OUT_DIR").expect("OUT_DIR")).join("i18n");
    fs::create_dir_all(&out_dir).expect("create OUT_DIR/i18n");

    let mut generated = String::from("pub static MESSAGES: &[(&str, &str)] = &[\n");
    let mut saw_base = false;

    for path in &files {
        let locale = path.file_stem().and_then(|s| s.to_str()).expect("utf-8");
        let raw = fs::read_to_string(path).unwrap_or_else(|e| panic!("read {}: {e}", path.display()));
        let doc: serde_json::Map<String, serde_json::Value> = serde_json::from_str(&raw)
            .unwrap_or_else(|e| panic!("{}: invalid JSON: {e}", path.display()));

        let subset: BTreeMap<&str, &serde_json::Value> = doc
            .iter()
            .filter(|(k, _)| k.starts_with("api_error_") || k.starts_with("email_"))
            .map(|(k, v)| (k.as_str(), v))
            .collect();

        if subset.is_empty() {
            continue;
        }
        saw_base |= locale == BASE_LOCALE;

        let target = out_dir.join(format!("{locale}.json"));
        fs::write(&target, serde_json::to_string(&subset).expect("serialize")).expect("write");
        generated.push_str(&format!("    ({locale:?}, include_str!({:?})),\n", target.to_string_lossy()));
    }
    generated.push_str("];\n");

    assert!(saw_base, "Base locale `{BASE_LOCALE}.json` missing in `{}`", dir.display());
    fs::write(Path::new(&env::var("OUT_DIR").unwrap()).join("embedded_messages.rs"), generated)
        .expect("write embedded_messages.rs");
}
```

```rust
use std::future::Future;
use crate::locale::Locale;

tokio::task_local! {
    static CURRENT_LOCALE: Locale;
}

/// Retrieve the current task's active locale, falling back to default "en".
pub fn current_locale() -> Locale {
    CURRENT_LOCALE
        .try_with(|loc| loc.clone())
        .unwrap_or_else(|_| Locale::default())
}

/// Run a future scoped to a specific requested locale.
pub async fn with_locale<F>(locale: Locale, future: F) -> F::Output
where
    F: Future,
{
    CURRENT_LOCALE.scope(locale, future).await
}
```

```rust
use std::sync::OnceLock;
use crate::{
    catalog::{Catalog, CatalogBuilder},
    locale::Locale,
    message::Args,
};

mod embedded {
    include!(concat!(env!("OUT_DIR"), "/embedded_messages.rs"));
}

static EMBEDDED_CATALOG: OnceLock<Catalog> = OnceLock::new();

pub fn embedded_catalog() -> &'static Catalog {
    EMBEDDED_CATALOG.get_or_init(|| {
        let mut builder = CatalogBuilder::new(Locale::default());
        for (locale, json) in embedded::MESSAGES {
            if let Ok(b) = builder.add_json(locale, json) {
                builder = b;
            }
        }
        builder.build().expect("embedded catalog must build cleanly")
    })
}

/// Convert an API error code (`auth:invalid_credentials`) to an i18n key (`api_error_auth_invalid_credentials`).
pub fn error_code_to_key(code: &str) -> String {
    format!("api_error_{}", code.replace([':', '-', '.'], "_"))
}

/// Localize an error code for the given locale using the embedded catalog and variable arguments.
pub fn localize_error(code: &str, locale: &Locale, args: &Args) -> Option<String> {
    let key = error_code_to_key(code);
    let cat = embedded_catalog();
    let resolved_locale = cat.negotiate([locale.as_str()]);
    cat.format(&resolved_locale, &key, args).ok()
}
```

```rust
impl IntoResponse for AppError {
    fn into_response(self) -> Response<Body> {
        let status = self.status_code();
        let error_code = self.error_code();
        let raw_message = self.to_string();
        let raw_details = self.details();
        let req_locale = cms_i18n::current_locale();

        let mut args = cms_i18n::Args::new();
        match &self {
            AppError::NotFound(path) => { args.insert("path", path); }
            AppError::Conflict(d) | AppError::PreconditionFailed(d) | AppError::Validation(d)
            | AppError::InvalidInput(d) | AppError::Storage(d) | AppError::ImportFailed(d) => {
                args.insert("details", d);
            }
            _ => {}
        }

        let i18n_key = cms_i18n::error_code_to_key(&error_code);
        let localized_msg = cms_i18n::localize_error(&error_code, &req_locale, &args);

        let (message, details, error_id) = if status.is_server_error() {
            let error_id = uuid::Uuid::new_v4().to_string();
            let safe_msg = localized_msg.unwrap_or_else(|| {
                match &self {
                    AppError::Database(_)
                    | AppError::DatabaseConnectionFailed
                    | AppError::TransactionFailed => "An internal database error occurred".to_string(),
                    _ => "An internal server error occurred".to_string(),
                }
            });
            tracing::error!(status = %status, error_id = %error_id, error_code = %error_code, error = %raw_message, "AppError Server Error");
            (safe_msg, Some(serde_json::json!({ "errorId": error_id })), Some(error_id))
        } else {
            if status.is_client_error() {
                tracing::warn!(status = %status, error_code = %error_code, error = %raw_message, "AppError Client Error");
            }
            (localized_msg.unwrap_or(raw_message), raw_details, None)
        };

        let body = ApiErrorResponse {
            error: ApiError {
                code: error_code,
                message,
                details,
                request_id: error_id.clone(),
                i18n: Some(ApiErrorI18n {
                    key: i18n_key,
                    args: if args.is_empty() { None } else { Some(args.into_iter().map(|(k, v)| (k.to_string(), v.to_string())).collect()) },
                }),
            },
        };

        let json_body = serde_json::to_string(&body).unwrap();
        let mut builder = Response::builder()
            .status(status)
            .header("Content-Type", "application/json")
            .header("Content-Language", req_locale.as_str());

        if let Some(ref eid) = error_id {
            builder = builder.header("X-Error-ID", eid);
        }

        builder.body(Body::from(json_body)).unwrap()
    }
}
```
